# Cafe Sales Analysis

## About the Project

This project is about cleaning and analyzing cafe sales data using Microsoft Excel. I started with a raw dataset containing several data issues and processed it to make the data ready for analysis.

Through this project, I wanted to understand the sales data, explore sales patterns, and find useful insights from the transactions.

## Dataset

The dataset was obtained from Kaggle:

[Cafe Sales - Dirty Data for Cleaning Training](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training)

- Original data: 10,000 records
- Cleaned data: 9,943 records

## What I Did

**1. Data Cleaning**
- Checked missing and invalid values.
- Handled inconsistent data.
- Reviewed and validated the cleaned dataset.

**2. Data Analysis**
- Analyzed sales performance.
- Compared product and category sales.
- Explored transaction patterns.
- Identified sales trends.

**3. Data Visualization**
- Created charts and visualizations in Excel.
- Used the results to build a sales dashboard.

## Tools Used

- Microsoft Excel
  - Data Cleaning
  - Pivot Tables
  - Data Analysis
  - Charts & Dashboard
